# OpenToonz - Frames You Draw

OpenToonz is an animation program for artwork you create. Levels hold drawings. The camera frames what you will export. Nothing in the install is a cartoon you are given to recut.

---

## Product Snapshot

Start a scene, draw or scan a level you made, and expose it for a few frames. Play that. If the motion is unclear, add a drawing rather than a long empty timeline. The camera can move later. A first scene that already exports is more useful than a reel you have not saved.

Export a short movie to a new file and watch it in a normal player. The project stays in its folder with the drawings. If you move one piece and not the other, the scene breaks even though the files still exist. Keep them together.

## Highlights

- Drawings you make, on levels
- Frames you expose and play
- A camera you set when the drawings already work
- A project folder you save
- An export that is a separate movie
- No built-in film to trace

---

## Live Production

Use it for a short action you can finish: a blink, a walk cycle you drew, a title you lettered. Save after the first playback inside OpenToonz. Then render. If the movie stutters or crops, change the project and render again. Do not edit the movie as if it were the scene.

Store the folder where you back up other work. A crash loses unsaved frames. OpenToonz will not clear rights to someone else's footage.

---

## Scene and Render

The scene file plus the level drawings are the source. The render is a delivery. Name the render so you do not overwrite the only good movie while you try a second camera. Delete a bad render, not the levels. A palette you change affects the drawings. Look at one frame before you repaint a whole level.

---

## Setup Path

Prerequisites: A folder for the project, and a short idea you will draw.

1. Install OpenToonz and create a scene in that folder.
2. Draw a few frames and play them.
3. Save the project.
4. Render a short movie to a new name.
5. Watch it outside OpenToonz. Keep the project folder.

## Who Benefits

OpenToonz fits a short scene you draw yourself. It does not fit tracing a film you do not own, a render-only workflow that throws away the project, or a first day spent on a long unfinished reel.

---

## Fixes

Playback is blank: the level is not exposed, or the drawings were moved. Put the folder back together. The render crops: change the camera in the project and render again. Frames were not saved: they are gone. Save earlier next time. You wanted to trace a commercial film: stop.
